# StampdUp Pinterest Template Library

Eight editable 1000 × 1500 SVG templates plus PNG previews. Built for StampdUp Travel using the approved green, gold, cream, coral, PinLogo, and StampdUp Travel logo.

## Templates

1. Hero photo + bold headline
2. Numbered checklist
3. Mistakes to avoid
4. Side-by-side comparison
5. Timeline / step-by-step
6. Packing / document flat lay
7. Safety warning
8. Quick-reference card

## Codex production rules

- Choose the template that fits the concept; do not cycle templates by Pin number.
- Replace only labeled photo/text placeholders while preserving the canvas, safe margins, palette, logo area, and hierarchy.
- Use supplied approved logos. Never redraw them.
- Internal Pin IDs belong in filenames and metadata only, never on artwork.
- Keep headlines to roughly 2–8 words and support copy short enough to remain mobile-readable.
- Render final Pins to PNG at exactly 1000 × 1500.
- Reject overflow, clipping, misspellings, low contrast, or excessive empty space.
- Use a new immutable versioned filename whenever artwork changes.
- Build a contact sheet from live production URLs and obtain visual approval before CSV generation.

## Editing

SVG groups and placeholders are named where practical. Open SVG masters in Figma, Illustrator, Inkscape, or edit them as XML/HTML. PNG files are previews, not editable masters.
